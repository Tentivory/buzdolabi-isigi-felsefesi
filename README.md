# Buzdolabı Işığı Felsefesi

> Resmi adı: Kapı Açılınca Var Olan Aydınlatma Dairesi (KAVOAD)

Bu depo, evrendeki en kısa ömürlü memuru simüle eder. Görevi: kapı açılınca yanmak, kapanınca yok olmak, arada da ciddi bir rapor yazmak.

Hiçbir şey pişirmez. Hiçbir şey soğutmaz. Sadece bakar ve yargılar.

## Neden var

Çünkü biri kapıyı açtı. Başka sebep aranmayacak. Arayan kişi dosyayı kendine kapatır.

## Kurulum

Python 3 yeter. Bağımlılık yok. Market fişi de yok.

```bash
python buzdolabi_isigi.py
```

İnteraktif mod:

```bash
python buzdolabi_isigi.py --kapi acik --raf orta --saat 03:14
```

## Ne yapar

- Kapı durumuna göre ışığı yakar veya söndürür.
- Raf, saat ve el hareketine göre abartılı bir varoluş raporu üretir.
- Her oturumun sonuna resmi damga basar.
- Gizli bir dipnot dosyası tutar. Oraya bakmak zorunlu değil. Zorunlu olmayan şeyler genelde daha ciddidir.

## Lisans

Kapı açıkken MIT, kapı kapalıyken yok hükmünde.
